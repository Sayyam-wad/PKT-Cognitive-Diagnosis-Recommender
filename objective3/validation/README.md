# Converter validation: code to copy (35 submissions)

These are real Codeforces submissions that correspond one-to-one to records in our dataset (aligned with the official Codeforces API). Codeforces does not allow automated downloading of submission pages, so please copy them by hand:

1. Open each link in a browser (log in to Codeforces if the source is hidden).
2. Copy the full source code exactly as shown (all lines, including `#include`s and macros).
3. Save it as `validation/code/<file name>` using the name in the table, UTF-8 text.
4. When done, run from the `objective3_ksap` folder:  `python validation/validate_converter.py`  (needs `pip install libclang==13.0.0 pcpp`).

Even 15-20 files are enough for a first parity check; do them in order (whole learners first).
